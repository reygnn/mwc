## A. Defects

1. **A tool that asks for maximized or fullscreen before it maps is docked in that
   state.** Before the first map `dock_order` is -1, so `view_maximize_at()` and
   `view_fullscreen_at()` (src/view.c) keep the request; `view_handle_map()` docks the
   window without dropping it. `dock_config_changed()` drops these states on a reload,
   the map path does not. Maximized loops: the dock box takes the maximized width,
   `set_box()` shrinks the usable area, `views_usable_area_changed()` refits the docked
   window, its commit rearranges the dock, and so on: 3087 configures in 3 s with
   `xdgc pre=max`. Fullscreen gives a dock as big as the output, whose strip the
   "reserves more than there is" fallback discards. GTK programs that remember being
   maximized do this. X11 is fine (`xw_map` goes through the gated setters).
   [Fix: one helper that drops maximized, snap, fullscreen and the tab group, used at
   map and on reload; as a guard, skip docked windows in `views_usable_area_changed()`.]

2. **Lower puts a docked window under the dock frame.** The frame is a sibling of the
   docked windows in `layer_shell[2]`, lowered to the bottom only in `dock_arrange()`.
   Alt+F3, Lower in the window menu, a middle click on the title and Alt+Shift+Tab
   (`view_lower_one()`, src/view.c) put the tool below it: hidden and, since a click on
   the frame is swallowed, unreachable until the next arrange.
   [Fix: the frame in a scene tree of its own between `layer_views` and
   `layer_shell[2]` (src/main.c): always above normal windows, always below docked
   ones, whatever is raised or lowered.]

3. **An X11 tool can move itself out of the dock.** `xw_request_configure()`
   (src/xwayland.c) keeps the place of maximized, fullscreen, snapped and tiled
   windows, not of docked ones. A position-only ConfigureRequest moves the window; no
   size change means no commit and no `dock_arrange()`. The dock keeps an empty slot.
   Programs that restore their position after mapping do this.
   [Fix: docked windows keep their place, the size is honoured; the commit rearranges.]

4. **A minimized window that gets a dock line on reload comes back outside the dock.**
   `dock_config_changed()` leaves it an icon; `view_restore()` doesn't rearrange the
   dock. Restored, it is marked docked but sits where it was: it can't be moved or
   minimized again, Alt+Tab skips it.
   [Fix: restore docked windows in `dock_config_changed()`.]

5. **`_NET_WM_STATE_BELOW` takes a docked X11 window out of the above layer.**
   `own_layer()` checks `xsurface->below` before `view_docked()`.
   [Fix: docked first.]

6. **Membership is only worked out at map and on reload.** An app_id or WM_CLASS set
   after mapping (`xdg_set_app_id`, `xw_set_class`; xdgc `late_app` shows it) docks
   only at the next reload. A docked window that later gets a parent or a dialog type
   stays docked, a dialog that loses its parent is never docked.
   [Fix: `dock_view_changed(view)` recomputes `dock_order` and, on a change, does what
   a reload does for that one window; called from the app_id, class, parent and type
   handlers.]

7. **`dock_order` is kept while unmapped.** The stale value steers the first configure's
   functions and `view_fullscreen_at()`. If a reload removed the line in between, the
   first frame lacks its buttons, as decorations are only updated at map for docked
   windows.
   [Fix: reset to -1 on unmap; update decorations at map always.]

8. **On a reload the dock is laid out from sizes not yet committed.** Unmaximizing,
   untiling or ungrouping a newly docked window only asks for the smaller size;
   `dock_arrange()` uses the old one, so other maximized windows are refitted twice.
   The end state is right.
   [Leave it: one round trip, only on a reload that changes the dock.]

9. **The dock's strip skips the panel throttle.** `set_box()` calls `layer_arrange()`
   at once. A tool that changes its height on every frame makes mwc refit every
   maximized and tiled window each frame; layer.c throttles exactly that for panels
   (ARRANGE_MS).
   [Fix: through the same throttle.]

10. **The frame buffer is drawn anew on every arrange,** also when size and theme are
    unchanged: a tool whose width changes often (a clock with proportional digits)
    costs a full redraw each time.
    [Fix: keep the last size, redraw on a change or a reload.]

## B. Style

11. **Five copies of the name and class lookup** in src/config.c (shades, tiling,
    position, allDesktops, dock), and `config_view_dock()` repeats
    `config_view_position()`'s top-level guard. [A `view_rule(view, resource)` helper
    and a `toplevel_only(view)` predicate.]

12. **Placement defaults written twice** (static initializers and
    `load_icon_placement()`, which now loads both); `struct config_icon_placement`
    serves both. [Defaults as constants used in both places; `load_placements()`,
    `struct config_placement`.]

13. **`theme.bevel + 1` in three places** (frame.c, iconbox.c, dock.c). [One helper.]

14. **The dock orders equal lines by `tile_seq`.** Works, as every map sets it, but
    couples the dock to tiling's field. [A comment saying why.]

15. **The same three-line hook three times** (`view_apply_size`, `view_frame_changed`,
    `xw_commit`). [`dock_view_changed(view)` from 6 covers these too.]

16. **`dock_rect()` plus `wlr_box_contains_point()` in input.c,** where the icon box has
    `iconbox_contains()`. [`dock_contains(lx, ly)`; drop `dock_rect()`.]

17. **Map computes properties, then decorations again** for docked windows. [Goes away
    with 7.]

18. **`frame_render()` for every view in `dock_config_changed()`** is redundant:
    decorations re-render on a change, the reload already ran `view_theme_changed()`.
    [Drop it.]

19. **Comments hard to parse:** the frame's in `dock_init()`, `dock_output_gone()` and
    `config_view_dock()` in mwc.h; `in_turn()` is a vague name. [Rewrite; `cyclable()`.]

20. **`dock_output_gone()` is called from `layer_output_gone()`,** though the dock isn't
    layer-shell; right only because both output-gone paths pass there. [Say so.]

21. Small: redundant `refresh` before `check` in dock.sh, uneven `# ----` rulers, a
    93-character line in CAVEATS.md. [Fix.]
